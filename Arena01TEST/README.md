# Практическая работа 01 · Арена новичка

## Среда
- JDK 21
- Вариант: А · Руины (Крыса 12 HP / 4 урона, Скелет 18 HP / 6 урона, Страж 24 HP / 8 урона, сила героя 10)

## Запуск
```bash
javac -encoding UTF-8 -d out src/Main.java
java -cp out Main
```

## Правила допуска
Уровень героя не ниже 10 И (есть щит ИЛИ класс — маг).
При отказе первой проверяется недостаточность уровня, затем — отсутствие защиты.

## Контрольные сценарии (проверено вручную по методичке)
1. Полный проход, вариант А**: имя Артур, класс воин, уровень 10, щит да, во всех боях команда «атака».
   Результат: Раунд 1 — победа, HP 36, XP 20; Раунд 2 — победа, HP 30, XP 40; Раунд 3 — победа, HP 14, XP 60; итог — «Арена пройдена, побед 3».
2. Отказ по уровню: воин, уровень 9, щит есть → «Отказ: недостаточный уровень».
3. Допуск без щита: маг, уровень 10, щита нет → «Допущен».
4. Отказ по защите: воин, уровень 10, щита нет → «Отказ: отсутствие нужной защиты».
5. Неизвестная команда: HP, XP и право лечения не меняются, ответного удара нет.
6. Повторное лечение в одном бою: второй вызов отклоняется, ответной атаки противника нет.
7. Выход командой 0: итог «Игра прервана», опыт за текущего противника не начисляется.

## Известные ограничения
- Случайность не используется — поведение полностью детерминировано (по условию работы).
- Реализован только вариант А; структура алгоритма одинакова для всех трёх вариантов.
